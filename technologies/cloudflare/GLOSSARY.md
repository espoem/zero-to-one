# Bilingual Glossary: Cloudflare Edge Architecture & The Workers Runtime

A comprehensive English ↔ Czech terminology index defining formal concepts across edge computing, the `workerd` V8 isolate runtime, actor-model state with Durable Objects, distributed edge storage, and Zero Trust security architectures.

---

| Canonical English Term | Czech Equivalent | Concise English Definition | Primary Source / Reference |
| --- | --- | --- | --- |
| Anycast Routing | Anycastové směrování | Network addressing and routing method where a single destination IP address is simultaneously advertised from multiple global routing nodes (Points of Presence), routing incoming packets to the topologically closest edge node via BGP. | RFC 4786 / Cloudflare Architecture |
| Capability Binding | Schopnostní vazba (Capability binding) | A fine-grained, secure runtime link injected into a Worker's execution context granting explicit permission to access an external edge resource (KV, D1, R2, DO, Service) without exposing network credentials or API tokens. | `workerd` Security Architecture |
| Cloudflare Access | Cloudflare Access | An identity-aware reverse proxy (IAP) enforcing Zero Trust authentication and granular authorization policies before requests reach origin servers or edge microservices. | Cloudflare Zero Trust Documentation |
| Cloudflare Tunnel (`cloudflared`) | Tunel Cloudflare | A lightweight edge daemon establishing encrypted outbound-only tunnels to Cloudflare edge PoPs, exposing private services without opening inbound firewall ports or public IP addresses. | Cloudflare One Documentation |
| Cloudflare Workflows | Cloudflare Workflows | A distributed, stateful execution engine orchestrating multi-step asynchronous business logic with automatic retry policies, step memoization, and durable sleep semantics built on Durable Objects. | Cloudflare Workflows GA Documentation |
| Compatibility Date | Datum kompatibility | A designated calendar date string (e.g., `YYYY-MM-DD`) in `wrangler.jsonc` that pins the runtime behavior, polyfill semantics, and global standard API compliance of a Worker to prevent breaking changes. | Cloudflare Workers Runtime Docs |
| Compatibility Flag | Příznak kompatibility | A fine-grained toggle (e.g., `nodejs_compat`, `transformstream_enable_standard_constructor`) enabling or disabling specific runtime behaviors or beta features independently of the compatibility date. | Cloudflare Workers Configuration |
| Cron Trigger | Časovaný spouštěč (Cron trigger) | A recurring background schedule defined via crontab syntax that periodically dispatches scheduled events directly into a Worker's `scheduled` export without external polling. | Cloudflare Workers Platform Docs |
| D1 Database | Databáze D1 | A serverless distributed relational SQL database engine built on SQLite, featuring single-primary transactional writes, read replication, and automated snapshot backups. | Cloudflare D1 Architecture Docs |
| Dead-Letter Queue (DLQ) | Fronta nedoručených zpráv (DLQ) | A secondary queue destination where messages that fail consumption after exhausting the configured retry threshold are routed for diagnostic isolation and manual redrive. | Cloudflare Queues Documentation |
| Durable Object | Trvalý objekt (Durable Object) | A globally unique, single-threaded distributed actor coordinating stateful operations, transactional persistence (SQLite or KV), WebSocket hibernation, and alarms across the edge network. | Cloudflare Durable Objects Docs |
| Edge Cache | Hraniční mezipaměť | A geographically distributed cache storage layer collocated within edge data centers (PoPs) storing HTTP responses close to client endpoints per RFC 9111 rules and Cache API directives. | Cloudflare Cache Architecture Docs |
| Edge Runtime (`workerd`) | Hraniční běhové prostředí | An open-source, web-standard-compliant JavaScript and WebAssembly runtime developed by Cloudflare based on the V8 engine, executing thousands of isolated sandboxes within a single Unix process. | `cloudflare/workerd` GitHub Repository |
| Eventual Consistency | Konečná konzistence | A distributed storage model where updates made to a primary replica propagate asynchronously across nodes, guaranteeing that all replicas eventually converge in the absence of new writes. | Distributed Systems Standards / RFCs |
| Hyperdrive | Hyperdrive | A global edge connection pooling and query acceleration engine that accelerates distributed connections to regional PostgreSQL and MySQL databases while caching read queries. | Cloudflare Hyperdrive Documentation |
| Input Gate | Vstupní brána (Input gate) | An actor concurrency control mechanism in Durable Objects that serializes incoming RPC invocations and HTTP requests, preventing concurrent state modification while synchronous code executes. | Cloudflare Durable Objects Internals |
| Isolate | Izolát (V8 Isolate) | An isolated instance of the Google V8 JavaScript engine with its own discrete heap, call stack, and garbage collector, enabling sub-millisecond cold starts and dense multi-tenancy. | V8 Engine Specifications |
| Logpush | Dávkové odesílání protokolů (Logpush) | A high-throughput streaming pipeline for real-time delivery of edge analytics, WAF security logs, and Worker execution events to external SIEM or cloud storage destinations. | Cloudflare Analytics & Logs |
| Multipart Upload | Vícedílné nahrávání (Multipart upload) | An S3-compatible protocol in R2 for uploading large binary objects concurrently in discrete, numbered chunks and committing them atomically into a unified edge object. | Amazon S3 / Cloudflare R2 Documentation |
| Nanoservices | Nanoslužby | Ultra-lightweight microservices designed to execute discrete single-purpose tasks inside V8 isolates, communicating over zero-latency IPC or capability bindings without network hops. | `workerd` Design Specification |
| Negative Cache | Negativní mezipaměť | A caching mechanism that stores the absence of a requested resource (such as a 404 or missing KV key) for a configured TTL to shield origin servers and storage backends from stampedes. | RFC 2308 / Cloudflare Cache Docs |
| Output Gate | Výstupní brána (Output gate) | A concurrency mechanism in Durable Objects that prevents outgoing network responses or I/O completions from being observed until preceding storage write transactions have committed to disk. | Cloudflare Durable Objects Internals |
| Point of Presence (PoP) | Bod přítomnosti (PoP) | An edge data center facility housing Cloudflare server infrastructure situated at global internet exchange points (IXPs) to terminate Anycast traffic close to end users. | Internet Infrastructure Standards |
| Presigned URL | Předběžně podepsaná URL | A cryptographic time-bounded URL allowing unauthenticated clients to securely upload or download specific objects in R2 storage without exposing storage credentials. | Cloudflare R2 Storage Documentation |
| Queues | Zprávařské fronty (Cloudflare Queues) | A distributed message queue service providing at-least-once message delivery, automatic batching, consumer auto-scaling, and configurable retry and dead-letter queue routing. | Cloudflare Queues Documentation |
| R2 Object Storage | Objektové úložiště R2 | A globally distributed S3-compatible object storage system designed for zero-egress data egress fees, multi-region replication, and direct Worker binding access. | Cloudflare R2 Documentation |
| Service Binding | Služební vazba (Service binding) | An in-process or low-latency inter-worker communication binding that allows one Worker to invoke another Worker's exported handlers via direct RPC without routing across the public internet. | Cloudflare Workers Architecture Docs |
| Sessions API | Rozhraní Sessions (D1) | A sequential consistency mechanism in D1 using cryptographic bookmark tokens to guarantee read-your-writes consistency across read-replicas within a client session. | Cloudflare D1 Architecture Docs |
| Smart Placement | Inteligentní umístění (Smart Placement) | An automated routing engine that analyzes database query patterns and dynamically migrates Worker execution to the data center closest to the backend database to minimize round-trip latency. | Cloudflare Workers Documentation |
| Spectre Mitigation | Zmírnění zranitelnosti Spectre | Hardening techniques implemented in `workerd`, including high-resolution timer coarsening and disallowing unconstrained shared array buffers, preventing microarchitectural side-channel attacks across isolates. | Cloudflare Security Research |
| Stale-While-Revalidate | Stale-While-Revalidate | An HTTP cache directive (`RFC 5861`) and Cache API behavior enabling the edge to serve an expired cached response immediately while asynchronously fetching an updated representation in the background. | RFC 5861 / HTTP Specifications |
| Tail Worker | Koncový Worker (Tail worker) | A specialized background Worker triggered upon the completion of another Worker's request execution, receiving structured telemetry and unhandled exception logs for streaming ingestion. | Cloudflare Workers Observability |
| Tiered Cache | Víceúrovňová mezipaměť (Tiered cache) | A hierarchical CDN topology where regional upper-tier data centers aggregate cache misses from lower-tier edge PoPs before forwarding requests to the origin, maximizing cache hit ratios. | Cloudflare Architecture Documentation |
| Time Travel | Cestování v čase (D1 Time Travel) | Point-in-time recovery and snapshot restoration functionality in D1 databases, allowing administrators to restore tables or entire databases to any minute within the retention window. | Cloudflare D1 Documentation |
| Turnstile | Turnstile | A privacy-preserving alternative to CAPTCHA that verifies browser legitimacy and detects automated bot traffic using non-interactive cryptographic proof-of-work and behavioral signals. | Cloudflare Application Security |
| V8 Engine | V8 JavaScript Engine | Google's open-source high-performance JavaScript and WebAssembly engine written in C++, compiling ECMAScript directly to native machine code using JIT compilers (Ignition & Sparkplug). | ECMAScript & Google V8 Docs |
| Web Application Firewall (WAF) | Aplikační firewall (WAF) | An edge security filter evaluating incoming HTTP traffic against managed rule sets (OWASP, zero-day CVEs) and custom firewall expressions to mitigate L7 injection and protocol attacks. | Cloudflare Security Documentation |
| WebSocket Hibernation | Uspání WebSocketu (WebSocket Hibernation) | A memory-optimization feature allowing a Durable Object to serialize and suspend its active JavaScript isolate while maintaining open TCP/WebSocket connections in edge infrastructure. | Cloudflare Durable Objects Docs |
| Worker Entrypoint | Vstupní bod Workeru | An exported class extending `WorkerEntrypoint` that exposes typed RPC methods to caller Workers over Service Bindings without requiring HTTP request/response serialization. | Cloudflare Workers Runtime Docs |
| Workers KV | Klíč-hodnota Workers (Workers KV) | A globally distributed, low-latency, key-value data store optimized for ultra-high read throughput, eventual consistency, and edge PoP caching with automatic negative lookup buffering. | Cloudflare Workers KV Documentation |
| Workers Static Assets | Statické prostředky Workers | The modern deployment architecture replacing legacy Cloudflare Pages, routing static files directly through edge storage and binding them to modern modular Workers. | Cloudflare Workers Documentation |
| `workerd` | `workerd` | The open-source V8-based application server and edge runtime powering Cloudflare Workers, architected around capability-based security, event loops, and lightweight nanoservices. | `cloudflare/workerd` Source Repository |
| Zero Trust | Nulová důvěra (Zero Trust) | A cybersecurity paradigm requiring continuous identity verification, posture validation, and cryptographic authorization for every user, device, and API request regardless of network perimeter. | NIST SP 800-207 Standards |
