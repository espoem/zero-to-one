# Kubernetes Glossary

This glossary defines core terminology used across Kubernetes orchestration, control plane mechanics, networking, storage, and security.

| English Term | Czech Term | Definition & Context | Primary Reference |
| :-- | :-- | :-- | :-- |
| **Idempotence / Idempotency** | **Idempotence** | The property of an operation where multiple identical executions yield the exact same system state as a single execution (`f(f(x)) = f(x)`). | ISO/IEC 2382, RFC 9110 (HTTP Semantics) |
| **Graceful Shutdown** | **Řádné ukončení služby (graceful shutdown)** | The coordinated termination procedure of stopping new traffic ingestion, draining in-flight requests within a bounded deadline, and releasing persistent connections. | Cloud-Native Operations Standards |
| **Load Shedding** | **Shazování zátěže (load shedding)** | An overload defense mechanism that proactively rejects excess incoming requests when queue depth, event-loop delay, or resource utilization crosses a critical threshold. | Beyer et al. (Site Reliability Engineering) |
| **Circuit Breaker** | **Jistič (circuit breaker)** | A fault-isolation pattern or memory safeguard that trips to fail fast when an upstream dependency degrades or when a node's memory reservation approaches exhaustion. | Nygard (Release It!) |
| **Lease** | **Pronájem (lease)** | A time-bounded grant of authority or lock ownership that expires automatically after a fixed time-to-live unless renewed by the holder. | Gray & Cheriton (SOSP 1989) |
| **Fencing Token** | **Ohraničující token (fencing token)** | A monotonically increasing sequence number issued with each lock or lease acquisition; storage resources reject writes carrying a token lower than the highest token already observed. | Kleppmann (Designing Data-Intensive Applications) |
| **API Server** | **API server (řídicí rozhraní)** | The core control plane component that exposes the Kubernetes HTTP API, handling REST requests, schema validation, admission control, and state storage. | Kubernetes Architecture Docs |
| **etcd** | **etcd (distribuované úložiště)** | A distributed, consistent transactional key-value store implementing Raft consensus, serving as the primary backing data store for all Kubernetes cluster state. | etcd.io Specs |
| **Kubelet** | **Kubelet (uzlový agent)** | The primary node agent running on each worker node that registers the node, watches the apiserver, manages pod lifecycles, and reports status. | Kubernetes Architecture Docs |
| **Container Runtime Interface (CRI)** | **Rozhraní kontejnerového běhu (CRI)** | A gRPC-based plugin interface that enables the kubelet to communicate with various container runtimes (such as containerd or CRI-O). | Kubernetes KEP / CRI Spec |
| **Container Network Interface (CNI)** | **Rozhraní kontejnerové sítě (CNI)** | A specification and set of libraries for configuring network interfaces in Linux containers, standardizing pod IP allocation and overlay routing. | CNCF CNI Specification |
| **Container Storage Interface (CSI)** | **Rozhraní kontejnerového úložiště (CSI)** | A standard enabling storage vendors to expose block and file storage systems to containerized workloads across orchestration platforms. | CSI Specification |
| **Control Loop** | **Řídicí smyčka (control loop)** | An endless reconciliation loop (`reconcile`) that continuously observes the actual system state, compares it with the desired state, and takes corrective action. | Control Theory / Kubernetes Architecture |
| **Level-Triggered** | **Úrovňově spouštěný (level-triggered)** | A notification model where actions depend on the current persistent state rather than edge-triggered transient event notifications. | Kubernetes Design Principles |
| **Server-Side Apply (SSA)** | **Serverová aplikativní modifikace (Server-Side Apply)** | A declarative merge mechanism executed on the API server that tracks field ownership per manager to safely reconcile concurrent declarative updates. | Kubernetes API Conventions |
| **OwnerReference** | **Odkaz vlastníka (ownerReference)** | Metadata linking a dependent object to its creator object, enabling garbage collection and cascading deletion when the parent object is removed. | Kubernetes API Reference |
| **Pod** | **Pod (základní výpočetní jednotka)** | The smallest deployable computing unit in Kubernetes, representing a shared collection of Linux namespaces, cgroups, storage volumes, and one or more containers. | Kubernetes Pod Spec |
| **Init Container** | **Inicializační kontejner (init container)** | Specialized containers that run to completion before application containers start within a Pod, used for setup scripts, schema migrations, or dependency checks. | Kubernetes Workloads Spec |
| **Native Sidecar** | **Nativní sidecar kontejner (native sidecar)** | A container configured with `restartPolicy: Always` and lifecycle ordering that starts before application containers and terminates after them. | Kubernetes KEP |
| **Readiness Probe** | **Test připravenosti (readiness probe)** | A health check determining whether a container is ready to accept incoming network traffic; failures remove the pod from Service endpoint routing. | Kubernetes Pod Lifecycle |
| **Liveness Probe** | **Test živosti (liveness probe)** | A health check determining whether a container requires an automatic restart due to deadlock or unresponsive internal execution loops. | Kubernetes Pod Lifecycle |
| **Startup Probe** | **Test spuštění (startup probe)** | A health check that delays liveness and readiness probes until slow-starting legacy applications finish initialization. | Kubernetes Pod Lifecycle |
| **Deployment** | **Nasazení (Deployment)** | A higher-level workload controller providing declarative rolling updates and rollbacks for ReplicaSets and stateless pods. | Kubernetes Workloads API |
| **StatefulSet** | **Stavová sada (StatefulSet)** | A workload controller providing ordered deployment, scaling, unique network identifiers, and persistent stable storage volumes for stateful applications. | Kubernetes Workloads API |
| **DaemonSet** | **Sada démonů (DaemonSet)** | A workload controller ensuring that all or selected eligible cluster nodes run exactly one replica of a specified pod. | Kubernetes Workloads API |
| **ConfigMap** | **Konfigurační mapa (ConfigMap)** | An API object used to store non-confidential configuration key-value pairs consumable as environment variables, command-line arguments, or mounted files. | Kubernetes Configuration API |
| **Secret** | **Tajný klíč (Secret)** | An API object designed to store sensitive payloads (passwords, tokens, keys) with optional encryption at rest and secure volume projection. | Kubernetes Security API |
| **Horizontal Pod Autoscaler (HPA)** | **Vodorovný autoskaler podů (HPA)** | A controller that automatically adjusts the replica count of a deployment or statefulset based on observed CPU utilization or custom metrics. | Kubernetes Autoscaling API |
| **Vertical Pod Autoscaler (VPA)** | **Svislý autoskaler podů (VPA)** | A controller that analyzes container resource utilization and automatically adjusts CPU and memory request/limit declarations. | Kubernetes Autoscaling API |
| **Taint and Toleration** | **Skvrna a snášenlivost (Taint and Toleration)** | A scheduling mechanism allowing nodes to repel a set of pods unless the pods explicitly declare matching tolerations. | Kubernetes Scheduler API |
| **Node Affinity** | **Afinita uzlu (Node Affinity)** | Constraint rules expressed using labels that attract pods to run on specific groups of candidate nodes. | Kubernetes Scheduler API |
| **PodDisruptionBudget (PDB)** | **Rozpočet narušení podů (PDB)** | A policy object limiting the number of concurrent voluntary disruptions (drains, upgrades) that can affect a replicated application. | Kubernetes Policy API |
| **Service** | **Služba (Service)** | An abstract abstraction defining a logical set of Pods and a policy by which to access them via a stable virtual IP or DNS name. | Kubernetes Networking API |
| **EndpointSlice** | **Řez koncovými body (EndpointSlice)** | A scalable, segmented API resource replacing monolithic Endpoints to track network endpoints backing a Kubernetes Service. | Kubernetes Networking API |
| **CoreDNS** | **CoreDNS (klasická DNS služba)** | The modular, cluster-internal DNS server resolving internal service names and external DNS queries for pods. | CoreDNS Project / K8s Core |
| **NetworkPolicy** | **Síťová politika (NetworkPolicy)** | A declarative specification defining firewall-like ingress and egress connection rules between Pods and namespaces. | Kubernetes Networking API |
| **Gateway API** | **Bránové API (Gateway API)** | A role-oriented, extensible standard (GatewayClass, Gateway, HTTPRoute) replacing legacy Ingress for advanced traffic routing. | Kubernetes SIG-Network |
| **PersistentVolume (PV)** | **Trvalý svazek (PV)** | A piece of storage provisioned by an administrator or dynamically via StorageClasses, existing independently of individual pod lifecycles. | Kubernetes Storage API |
| **PersistentVolumeClaim (PVC)** | **Žádost o trvalý svazek (PVC)** | A user request for storage specifying capacity, access modes, and storage class requirements. | Kubernetes Storage API |
| **StorageClass** | **Třída úložiště (StorageClass)** | A definition of provisioners, parameters, and reclamation policies used for dynamic storage provisioning. | Kubernetes Storage API |
| **Kubeadm** | **Kubeadm (nástroj správy clusteru)** | A toolkit designed to bootstrap secure, conformant Kubernetes clusters following best practices. | Kubernetes Lifecycle SIG |
| **RBAC (Role-Based Access Control)** | **Řízení přístupu na základě rolí (RBAC)** | An authorization mechanism granting permissions through Roles, ClusterRoles, RoleBindings, and ClusterRoleBindings. | Kubernetes Authorization API |
| **Pod Security Standards** | **Standardy zabezpečení podů** | Predefined security profiles (Privileged, Baseline, Restricted) enforced across namespaces to restrict container privilege levels. | Kubernetes Security Standards |
| **ValidatingAdmissionPolicy** | **Ověřovací admisní politika** | A declarative admission control mechanism using Common Expression Language (CEL) without compiling external webhooks. | Kubernetes API Machinery |
| **CustomResourceDefinition (CRD)** | **Definice vlastního zdroje (CRD)** | An extension mechanism allowing cluster administrators to define custom API resource types and schemas. | Kubernetes API Machinery |
| **Operator Pattern** | **Operátorový vzor (Operator Pattern)** | A design pattern combining custom resource definitions with custom controllers to automate complex application operational tasks. | CoreOS / Kubernetes Patterns |
| **Helm** | **Helm (správce balíčků)** | The package manager for Kubernetes used to package, configure, and deploy multi-resource applications via charts. | CNCF Helm Project |
| **Kustomize** | **Kustomize (konfigurace bez šablon)** | A tool for customizing declarative Kubernetes YAML configuration files through overlays without template engines. | Kubernetes SIG-CLI |
| **Ephemeral Container** | **Pomíjivý kontejner (Ephemeral Container)** | A specialized container temporarily injected into a running pod for live troubleshooting and diagnostics. | Kubernetes KEP |
