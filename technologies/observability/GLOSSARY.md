# Observability Glossary

Bilingual English ↔ Czech terminology index for the **Observability** track, covering OpenTelemetry, Prometheus, PromQL, Loki, Tempo, Mimir, Grafana, Elastic APM, and SRE SLO metrics.

> [!IMPORTANT]
> Terms shared with the root glossary (`Idempotence / Idempotency`, `Graceful Shutdown`, `Load Shedding`, `Circuit Breaker`, `Lease`, `Fencing Token`, `Backpressure`) are copied verbatim from root `GLOSSARY.md`.

| English Term | Czech Term | Definition & Context | Primary Reference |
| :-- | :-- | :-- | :-- |
| **Observability** | **Pozorovatelnost** | A measure of how well internal system states can be inferred from knowledge of its external outputs (metrics, logs, traces). | Control Engineering & SRE Theory |
| **Telemetry Signal** | **Telemetrický signál** | Machine-generated data streams emitted by systems to report runtime behavior (metrics, logs, traces, profiles). | OpenTelemetry Specification |
| **Cardinality** | **Kardinalita** | The number of unique time-series data combinations generated by the cross-product of metric labels and their discrete values. | Prometheus TSDB Architecture |
| **Dimensionality** | **Dimenzionalita** | The number and type of label dimensions attached to a metric time series enabling multi-axis slicing and filtering. | Prometheus Data Model |
| **Push vs. Pull Telemetry** | **Push vs. Pull telemetrie** | Pull models involve telemetry collectors scraping endpoints periodically; push models involve instrumented applications transmitting data outbound to receivers. | Distributed Systems Architecture |
| **Sampling** | **Vzorkování** | The practice of selecting a subset of telemetry data (spans, logs, traces) to record and transmit, reducing network bandwidth and storage costs. | Distributed Tracing Standards |
| **Head Sampling** | **Hlavičkové vzorkování** | Decision-making at the start of a transaction (span creation) whether to record the trace, risking loss of rare error traces. | OpenTelemetry SDK Specification |
| **Tail Sampling** | **Ocasní vzorkování** | Evaluating completed trace trees against filtering criteria (e.g., error status, high latency) before persistence in backend storage. | OpenTelemetry Collector Architecture |
| **RED Method** | **Metoda RED** | A microservices monitoring methodology focusing on Rate (requests/sec), Errors (failed requests/sec), and Duration (latency distribution). | Tom Wilkie (Grafana Labs) |
| **USE Method** | **Metoda USE** | A resource monitoring methodology focusing on Utilization, Saturation, and Errors for every hardware and software resource. | Brendan Gregg |
| **Golden Signals** | **Zlaté signály** | Four core metrics defining SRE user experience: Latency, Traffic, Errors, and Saturation. | Google SRE Book |
| **OpenTelemetry (OTel)** | **OpenTelemetry (OTel)** | A vendor-neutral, CNCF-backed observability framework providing standardized APIs, SDKs, and collectors for telemetry generation and export. | CNCF OpenTelemetry Project |
| **W3C Trace Context** | **W3C Trace Context** | Standardized HTTP headers (`traceparent`, `tracestate`) ensuring interoperable distributed trace propagation across heterogeneous runtimes. | W3C Recommendation |
| **Span** | **Span (intervalová operace)** | The fundamental unit of distributed tracing representing a contiguous operation execution block with start/end times, attributes, and events. | OpenTelemetry Tracing Specification |
| **Trace** | **Trace (distribuovaná stopa)** | A tree of spans representing the end-to-end execution path of a request across distributed services. | OpenTelemetry Tracing Specification |
| **Baggage** | **Baggage (kontextová zavazadla)** | Contextual key-value pairs propagated alongside distributed traces across process boundaries to pass metadata down the call stack. | OpenTelemetry Context Specification |
| **Metric Temporality** | **Časová povaha metrik** | The semantic recording model of metrics: Cumulative (monotonically increasing since process start) vs. Delta (change since last collection). | OpenTelemetry Metrics Specification |
| **Exemplar** | **Exemplář (vzorový prvek)** | A specific trace ID reference attached directly to a metric sample data point, bridging metrics and distributed tracing. | Prometheus & OpenTelemetry Specifications |
| **OTLP (OpenTelemetry Protocol)** | **OTLP (OpenTelemetry Protocol)** | The wire protocol used by OpenTelemetry to transmit telemetry data (metrics, logs, traces) over gRPC or HTTP/protobuf. | OpenTelemetry Protocol Specification |
| **Prometheus** | **Prometheus** | An open-source systems monitoring and alerting toolkit featuring a multidimensional data model and powerful query language (PromQL). | CNCF Prometheus Project |
| **Time Series Database (TSDB)** | **Časová databáze (TSDB)** | A specialized database optimized for storing and querying time-stamped numerical data series with high ingestion throughput. | Database Systems Architecture |
| **Write-Ahead Log (WAL)** | **Zápis do předstihového deníku (WAL)** | A durability protocol requiring state modifications to be flushed to non-volatile sequential log storage before the corresponding dirty page blocks are written to heap storage. | Mohan et al. (ARIES Recovery Algorithm) |
| **Native Histogram** | **Nativní histogram** | Prometheus 3.x metric storage structure using exponential bucket boundaries to record high-resolution latency distributions efficiently. | Prometheus 3.0 Architecture |
| **PromQL** | **PromQL** | Prometheus Query Language used to select, aggregate, rate-calculate, and transform time-series metrics. | Prometheus Documentation |
| **Instant Vector** | **Okamžitý vektor** | A PromQL dataset containing a single scalar sample for each time series at a specific timestamp. | Prometheus PromQL Specification |
| **Range Vector** | **Rozsahový vektor** | A PromQL dataset containing a set of all sample values over a backward-looking time window for each time series. | Prometheus PromQL Specification |
| **Alertmanager** | **Alertmanager** | A companion tool handling alert routing, grouping, silencing, inhibition, and notification dispatching from Prometheus. | Prometheus Alertmanager Specification |
| **Service Level Indicator (SLI)** | **Ukazatel úrovně služeb (SLI)** | A quantitative measure of a service's performance (e.g., successful request ratio, p99 latency). | Google SRE Book |
| **Service Level Objective (SLO)** | **Cíl úrovně služeb (SLO)** | A target reliability value or range set for an SLI over a specified evaluation period. | Google SRE Book |
| **Error Budget** | **Chybový rozpočet** | The allowable unreliability quota defined by an SLO (`100% - SLO target`), consumed by production failures and errors. | Google SRE Book |
| **Burn Rate** | **Rychlost spalování (rozpočtu)** | The rate at which an error budget is being consumed relative to its total window duration. | Google SRE Book |
| **Grafana Loki** | **Grafana Loki** | A horizontally scalable, highly available log aggregation system inspired by Prometheus, indexing log metadata rather than log text. | Grafana Labs Loki Architecture |
| **LogQL** | **LogQL** | Grafana Loki's query language for filtering, parsing, and aggregating log streams using metric and log selectors. | Grafana Loki Documentation |
| **Grafana Tempo** | **Grafana Tempo** | A high-volume, cost-effective distributed tracing backend utilizing object storage with no internal indexing requirement. | Grafana Labs Tempo Architecture |
| **TraceQL** | **TraceQL** | Grafana Tempo's query language designed to search and filter distributed trace spans and attributes. | Grafana Tempo Documentation |
| **Grafana Mimir** | **Grafana Mimir** | A horizontally scalable, multi-tenant long-term metrics storage backend compatible with Prometheus Remote Write. | Grafana Labs Mimir Architecture |
| **Grafana Alloy** | **Grafana Alloy** | Grafana's vendor-neutral OpenTelemetry-based collector distribution featuring River pipeline configuration syntax. | Grafana Labs Alloy Documentation |
| **Elastic Observability** | **Elastic Observability** | An enterprise observability solution integrating APM, metrics, logs, and synthetics within the Elastic Stack (Elasticsearch & Kibana). | Elastic Documentation |
| **ES\|QL** | **ES\|QL** | Elastic Search Query Language: a pipe-based search and analytics language for querying Elasticsearch data streams. | Elastic Documentation |
| **Idempotence / Idempotency** | **Idempotence** | The property of an operation where multiple identical executions yield the exact same system state as a single execution (`f(f(x)) = f(x)`). | ISO/IEC 2382, RFC 9110 (HTTP Semantics) |
| **Graceful Shutdown** | **Řádné ukončení služby (graceful shutdown)** | The coordinated termination procedure of stopping new traffic ingestion, draining in-flight requests within a bounded deadline, and releasing persistent connections. | Cloud-Native Operations Standards |
| **Load Shedding** | **Shazování zátěže (load shedding)** | An overload defense mechanism that proactively rejects excess incoming requests when queue depth, event-loop delay, or resource utilization crosses a critical threshold. | Beyer et al. (Site Reliability Engineering) |
| **Circuit Breaker** | **Jistič (circuit breaker)** | A fault-isolation pattern or memory safeguard that trips to fail fast when an upstream dependency degrades or when a node's memory reservation approaches exhaustion. | Nygard (Release It!) |
| **Lease** | **Pronájem (lease)** | A time-bounded grant of authority or lock ownership that expires automatically after a fixed time-to-live unless renewed by the holder. | Gray & Cheriton (SOSP 1989) |
| **Fencing Token** | **Ohraničující token (fencing token)** | A monotonically increasing sequence number issued with each lock or lease acquisition; storage resources reject writes carrying a token lower than the highest token already observed. | Kleppmann (Designing Data-Intensive Applications) |
| **Backpressure** | **Zpětný tlak (_backpressure_)** | The flow-control protocol where a slow consumer signals an upstream producer that intermediate buffers are full, pausing or throttling production until capacity drains. | Reactive Streams Specification, Node.js Streams |
