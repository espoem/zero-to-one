# Bilingual Glossary: Microsoft Azure Architecture & Cloud Engineering

A standardized English ↔ Czech terminology index defining formal concepts across Microsoft Azure tenancy and governance, Microsoft Entra ID and RBAC/ABAC authorization, ARM/Bicep and Deployment Stacks, virtual networking and Private Link DNS, compute and serverless runtimes, messaging, Azure Storage, Cosmos DB and relational data platforms, security, observability, and business continuity.

| App Registration vs. Enterprise Application (Service Principal) | Registrace aplikace vs. podniková aplikace (instanční objekt) | An App Registration is the global multi-tenant definition object (Application ID) in a home Entra tenant, whereas an Enterprise Application is the local Service Principal instance instantiated in each tenant where the app receives permissions and token claims. | Microsoft Entra ID Application & Service Principal Model |
| App Service Deployment Slot & Slot-Sticky Setting | Slot nasazení App Service a nastavení vázané na slot | A Deployment Slot is a live, separately addressable App Service hosting environment used for zero-downtime VIP swaps into production; a Slot-Sticky Setting (`slotSetting: true`) stays pinned to its slot rather than moving with application configuration during a swap. | Azure App Service Deployment Slots Documentation |
| Application Gateway (WAF v2) | Azure Application Gateway (WAF v2) | A regional Layer 7 HTTP/HTTPS reverse proxy and load balancer providing TLS termination, URL path-based routing, cookie-based session affinity, autoscaling, and an integrated Web Application Firewall (WAF) enforcing OWASP Core Rule Sets. | Azure Application Gateway Documentation |
| Application Security Group (ASG) | Skupina zabezpečení aplikací (ASG) | A logical network grouping construct attached to VM network interfaces that lets Network Security Group (NSG) rules target application tiers by semantic group rather than hardcoded IP CIDR ranges. | Azure Virtual Network ASG Documentation |

| Azure Files | Azure Files | A managed cloud file-share service supporting industry-standard SMB 3.1.1 and NFS v4.1 protocols over TCP 445 or Private Endpoints, with Standard (HDD/SSD) and Provisioned Premium (SSD) performance tiers. | Azure Files Documentation |
| Azure Front Door | Azure Front Door | A globally distributed Anycast Layer 7 HTTP/HTTPS reverse proxy, CDN, and WAF operating at Microsoft edge PoPs, providing global routing, TLS offload, caching, and Private Link origin connectivity. | Azure Front Door Architecture Documentation |
| Azure Functions Flex Consumption | Plán Flex Consumption služby Azure Functions | A Linux serverless hosting plan for Azure Functions combining per-second pay-per-execution billing with VNet integration, selectable instance memory sizes, Always Ready pre-warmed instances, and deterministic concurrency control. | Azure Functions Flex Consumption Hosting Plan |
| Azure Hybrid Benefit | Zvýhodněné hybridní využití Azure (Azure Hybrid Benefit) | A licensing entitlement allowing organizations with active Software Assurance or qualifying subscriptions to apply on-premises Windows Server, SQL Server, and Linux licenses to Azure VMs and SQL services at reduced compute rates. | Azure Hybrid Benefit Documentation |
| Azure Load Balancer | Azure Load Balancer | A high-throughput Layer 4 (TCP/UDP) pass-through load balancer operating at regional or cross-region scope using 5-tuple hash distribution, health probes, and explicit outbound SNAT rules. | Azure Load Balancer Architecture Documentation |
| Azure Managed Redis | Azure Managed Redis | A fully managed in-memory data store built on Redis Enterprise providing sub-millisecond caching, clustering, RediSearch vector indexing, active geo-replication, and Entra ID token authentication, superseding legacy Azure Cache for Redis. | Azure Managed Redis Documentation |
| Azure Monitor Agent (AMA) | Agent Azure Monitor (AMA) | The modern telemetry collection agent for Azure VMs, VMSS, and Arc-enabled servers that replaces legacy Log Analytics (`MMA`/`OMS`) agents and uses Data Collection Rules (DCRs) to filter and route logs and metrics. | Azure Monitor Agent Overview |
| Azure NAT Gateway | Brána Azure NAT Gateway | A fully managed, zonally resilient outbound-only SNAT service attached to VNet subnets, providing 64,512 SNAT ports per assigned Public IP (up to 16 IPs) for deterministic, high-scale egress without SNAT port exhaustion. | Azure NAT Gateway Documentation |
| Azure NetApp Files | Azure NetApp Files | An enterprise bare-metal-backed, high-performance NAS file service powered by NetApp ONTAP supporting NFSv3, NFSv4.1, and SMB with sub-millisecond latencies and Ultra/Premium/Standard capacity pools. | Azure NetApp Files Documentation |
| Azure Policy | Zásada Azure (Azure Policy) | A preventive and detective governance engine evaluating ARM resource properties against JSON policy rules using effects including `Audit`, `Deny`, `Append`, `Modify`, `DeployIfNotExists`, and `DenyAction`. | Azure Policy Effects Documentation |
| Azure RBAC (actions vs. dataActions) | Řízení přístupu na základě role (Azure RBAC) | Azure's declarative authorization model mapping security principals to role definitions at a scope; `actions` govern ARM control-plane management operations, whereas `dataActions` govern direct service data-plane operations (e.g., reading blobs or secrets). | Azure Role-Based Access Control (RBAC) Documentation |
| Azure Service Bus (Peek-Lock, DLQ, Sessions, Duplicate Detection) | Azure Service Bus (Peek-Lock, DLQ, relace, detekce duplicit) | An enterprise AMQP message broker providing Peek-Lock transactional lease consumption, Dead-Letter Queues (DLQ) after `MaxDeliveryCount` failures, FIFO session serialization by `SessionId`, and window-based `MessageId` duplicate detection. | Azure Service Bus Messaging Documentation |
| Azure Site Recovery (ASR) | Azure Site Recovery (ASR) | A disaster recovery orchestration service providing continuous asynchronous block-level replication, recovery plans, and automated failover/failback for Azure VMs, VMware, and Hyper-V workloads across regions. | Azure Site Recovery Architecture Documentation |
| Azure SQL Hyperscale | Azure SQL Database Hyperscale | A cloud-native Azure SQL Database service tier that decouples compute nodes from distributed page servers and a log service, enabling rapid storage auto-scaling up to 128 TB and constant-time backups/restores independent of database size. | Azure SQL Database Hyperscale Architecture |
| Azure Traffic Manager | Azure Traffic Manager | A DNS-based global traffic load balancer returning endpoint DNS records according to routing methods (Priority, Weighted, Performance, Geographic, Multivalue, Subnet) without proxying application network packets. | Azure Traffic Manager Routing Documentation |
| Bicep | Jazyk Bicep | A concise, domain-specific Infrastructure-as-Code language with static type safety, modules, and user-defined types that transpiles deterministically into standard ARM JSON templates. | Microsoft Bicep Language Specification |
| CAF Landing Zone | Cílová zóna CAF (Azure Landing Zone) | A Cloud Adoption Framework reference architecture organizing platform and application subscriptions under a Management Group hierarchy with centralized networking, identity, security baselines, and Azure Policy guardrails. | Microsoft Cloud Adoption Framework (CAF) |
| Conditional Access | Podmíněný přístup (Conditional Access) | Microsoft Entra ID's zero-trust policy engine evaluating identity signals (user risk, device compliance, IP location, authentication strength) in real time to allow, require MFA/re-authentication, or block token issuance. | Microsoft Entra Conditional Access Documentation |
| Cosmos DB Change Feed | Informační kanál změn Cosmos DB (Change feed) | A persistent, ordered log of item inserts and updates within an Azure Cosmos DB container (available in Latest Version and All Versions and Deletes modes) consumed incrementally by Azure Functions or change feed processors. | Azure Cosmos DB Change Feed Documentation |
| Cosmos DB Hierarchical Partition Key | Hierarchický klíč oddílu Cosmos DB | A multi-level composite partition key (up to three levels, such as tenant, user, and session) allowing logical partitions to span beyond 20 GB while preserving single-partition query routing for prefix predicates. | Azure Cosmos DB Hierarchical Partition Keys |
| Cosmos DB Logical Partition (20 GB) | Logický oddíl Cosmos DB (limit 20 GB) | The fundamental unit of data grouping in Cosmos DB sharing the same partition key value; bounded strictly to 20 GB of storage, beyond which writes fail with HTTP 403 (substatus 1014). | Azure Cosmos DB Partitioning & Quotas |
| Cosmos DB Request Unit (RU/s) | Jednotka požadavku Cosmos DB (RU/s) | The normalized currency abstracting CPU, IOPS, and memory consumed by Cosmos DB operations (1 RU ≈ 1 KB point read); exceeding provisioned RU/s per second triggers HTTP 429 throttling with `x-ms-retry-after-ms`. | Azure Cosmos DB Request Units Documentation |
| Cosmos DB Session Token | Token relace Cosmos DB (Session token) | An opaque per-partition monotonically ordered vector clock (`x-ms-session-token`) issued on writes and passed by clients in Session consistency mode to guarantee read-your-own-writes across distributed replicas. | Azure Cosmos DB Consistency Levels |
| Dapr | Dapr (distribuované běhové prostředí aplikací) | Distributed Application Runtime—a CNCF sidecar framework integrated natively into Azure Container Apps providing portable building blocks for service invocation, state management, pub/sub messaging, and distributed bindings. | Dapr & Azure Container Apps Documentation |
| Data Collection Rule (DCR) | Pravidlo shromažďování dat (DCR) | An ARM resource defining ETL-like telemetry pipelines in Azure Monitor—specifying data sources, KQL ingestion-time transformations, and target Log Analytics tables or Azure Monitor metrics destinations. | Azure Monitor Data Collection Rules (DCR) |
| Default Outbound Access | Výchozí odchozí přístup (Default outbound access) | Legacy implicit internet egress assigned automatically to VMs in subnets without explicit outbound connectivity; retired for new VNets created with the Network API version released after 2026-03-31 (or created in the Azure Portal), where subnets default to private (`defaultOutboundAccess: false`); earlier API versions (including `2025-07-01`) retain the legacy default unless `defaultOutboundAccess: false` is set explicitly. | Azure Virtual Network Default Outbound Access |
| Delegated Subnet | Delegovaná podsíť | A subnet configured with `delegations` granting an Azure PaaS service (such as Azure Container Apps, App Service VNet integration, or PostgreSQL Flexible Server) permission to inject managed network interfaces and enforce service-specific policies. | Azure Subnet Delegation Documentation |
| Deny Assignment | Přiřazení odepření (Deny assignment) | A system-managed authorization block (created by Deployment Stacks, Managed Applications, or Blueprints) that blocks specified Azure RBAC actions for principals at a scope, overriding `Owner` and `Contributor` grants. | Azure Deny Assignments Documentation |
| Deployment Stack | Zásobník nasazení (Deployment stack) | An ARM lifecycle resource managing a collection of Bicep/ARM-deployed resources as an atomic unit with automated cleanup (`actionOnUnmanage`) and `denySettings` locks, replacing legacy Azure Blueprints. | Azure Deployment Stacks Documentation |
| DiskANN Vector Index | Vektorový index DiskANN | A disk-backed approximate nearest neighbor (ANN) graph indexing algorithm natively integrated into Azure Cosmos DB for low-latency, high-recall vector similarity search at billion-vector scale. | Azure Cosmos DB Vector Indexing (DiskANN) |
| Durable Functions Orchestrator | Orchestrátor Durable Functions | A stateful workflow coordination function built on the Durable Task Framework using event-sourcing replay; its execution code must be strictly deterministic (forbidding direct wall-clock reads, random GUIDs, or non-activity I/O). | Azure Durable Functions Code Constraints |
| Entra Tenant | Tenant Microsoft Entra | The dedicated, globally unique root directory instance of Microsoft Entra ID representing an organization, hosting its users, groups, app registrations, Conditional Access policies, and associated Azure Subscriptions. | Microsoft Entra Tenant Architecture |

| Instance Metadata Service (IMDS) | Služba metadat instancí (IMDS) | A non-routable link-local REST endpoint (`169.254.169.254`) accessible only from inside Azure VMs and VMSS instances (requiring header `Metadata: true`) to fetch instance topology metadata and Managed Identity OAuth 2.0 tokens. | Azure Instance Metadata Service Documentation |
| KEDA | KEDA (událostmi řízené škálování) | Kubernetes Event-driven Autoscaling—a CNCF autoscaler embedded in Azure Container Apps and AKS that scales container replicas between zero and N based on external event sources such as Service Bus queue depth, Kafka lag, or HTTP concurrency. | KEDA & Azure Container Apps Scaling |
| Key Vault Purge Protection | Ochrana před trvalým vymazáním v Key Vault (Purge protection) | An irreversible vault property enforcing mandatory retention (7–90 days) after soft deletion so neither administrators nor automation can permanently purge or recreate secrets, keys, or vaults with the same name until retention expires. | Azure Key Vault Soft-Delete & Purge Protection |
| Kusto Query Language (KQL) | Dotazovací jazyk Kusto (KQL) | A read-only, pipe-delimited (`\|`) tabular query language executed by Azure Data Explorer and Azure Monitor Log Analytics to filter, join, aggregate, and project time-series log and trace telemetry. | Kusto Query Language (KQL) Reference |
| Managed HSM | Spravovaný modul HSM (Managed HSM) | A fully managed, single-tenant, FIPS 140-3 Level 3 validated hardware security module service providing isolated cryptographic key generation, customer-controlled security domains, and RBAC key management. | Azure Key Vault Managed HSM Documentation |

| Private Endpoint | Privátní koncový bod (Private Endpoint) | A network interface injecting a private IP address from a VNet subnet directly into an Azure PaaS service or Private Link Service, keeping traffic on the Microsoft backbone and disabling public network exposure. | Azure Private Link & Private Endpoint |
| Privileged Identity Management (PIM) | Správa privilegovaných identit (PIM) | A Microsoft Entra ID Governance capability enforcing just-in-time (JIT), time-bound activation of eligible Entra ID and Azure RBAC privileged roles with MFA, justification, approval workflows, and audit trails. | Microsoft Entra PIM Documentation |
| PSRule for Azure | PSRule for Azure | An open-source static analysis rule suite (`PSRule.Rules.Azure`) validating Bicep files and compiled ARM JSON templates offline against Microsoft Well-Architected Framework security, reliability, and naming baselines in CI/CD. | PSRule for Azure Documentation |
| Remediation Task | Úloha nápravy (Remediation task) | An explicit Azure Policy execution job (`az policy remediation create`) required to retroactively apply `Modify` or `DeployIfNotExists` policies to pre-existing non-compliant resources, which policy assignment alone does not mutate. | Azure Policy Remediation Documentation |
