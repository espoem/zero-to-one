# Bilingual Glossary: GCP Architecture & Cloud Systems Engineering

A comprehensive English ↔ Czech terminology index defining formal concepts across Google Cloud resource governance, IAM inheritance, software-defined networking, compute virtualization, serverless architectures, distributed storage, database consistency, and Site Reliability Engineering (SRE).

| Bucket Lock | Uzamčení bucketu (Bucket Lock) | An irreversible compliance feature on Cloud Storage buckets that locks an existing retention policy, preventing modification or premature reduction of the retention period until all objects expire. | Google Cloud Storage Retention Policy Guide |
| Cloud Armor | Cloud Armor (Cloud Armor WAF) | A distributed web application firewall (WAF) and DDoS defense service built into the Google Front End (GFE) edge, providing Layer 7 filtering, IP rate limiting, adaptive protection, and preconfigured OWASP rules. | Google Cloud Armor Security Guide |
| Cloud Bigtable | Cloud Bigtable | A petabyte-scale, low-latency NoSQL wide-column database optimized for high-throughput reads and writes using sorted string tables (SSTables) and a single sorted row-key index. | Bigtable: A Distributed Storage System for Structured Data (OSDI 2006) |
| Cloud Interconnect | Cloud Interconnect (přímé propojení) | A high-bandwidth, enterprise-grade physical connection between an on-premises data center and Google's global network, available via Dedicated Interconnect (10G/100G/400G physical circuits) or Partner Interconnect. | Google Cloud Networking Architecture |
| Cloud NAT | Cloud NAT (překlad síťových adres) | A fully managed, software-defined egress network address translation service that enables private Compute Engine VMs and GKE nodes to initiate outbound internet traffic without external IP addresses. | Google Cloud NAT Documentation |
| Cloud Run Concurrency | Souběžnost v Cloud Run (Concurrency) | The maximum number of concurrent requests that a single Cloud Run container instance can process simultaneously (default 80, configurable up to 1000). | Google Cloud Run Developer Guide |
| Cloud Run Instance-Based Billing | Účtování Cloud Run na bázi instancí ("CPU always allocated") | A Cloud Run execution mode where CPU is allocated and billed continuously for the entire container lifecycle, enabling background threads and asynchronous processing outside active request boundaries. | Google Cloud Run Pricing & Architecture |
| Cloud Run Request-Based Billing | Účtování Cloud Run na bázi požadavků ("CPU allocated only during requests") | The default Cloud Run billing model where CPU is allocated and billed only while an HTTP request is actively being processed, throttling background CPU cycles to near zero when idle. | Google Cloud Run Developer Guide |
| Cloud Spanner | Cloud Spanner | A globally distributed, enterprise-grade relational database providing external consistency (ACID transactions) across regions without locking using TrueTime atomic clocks and Paxos consensus. | Spanner: Google's Globally-Distributed Database (OSDI 2012) |
| Cloud Tasks | Cloud Tasks (úlohová fronta) | A managed asynchronous task execution service designed for point-to-point task dispatch with fine-grained rate-limiting, deduplication, retry policies, and scheduled future execution. | Google Cloud Tasks Documentation |
| Committed Use Discount (CUD) | Sleva za závazek využití (CUD) | A contractual Google Cloud discount offering up to 57% savings in exchange for a 1-year or 3-year commitment to a predictable volume of compute resources or hourly spend. | Google Cloud Billing & FinOps Guide |
| Customer-Managed Encryption Key (CMEK) | Zákazníkem spravovaný šifrovací klíč (CMEK) | A cryptographic pattern where Google Cloud services encrypt data at rest using a key created, managed, and rotated by the customer in Cloud Key Management Service (Cloud KMS). | Google Cloud Security & Cryptography Guide |
| Datastore Mode | Režim Datastore (Firestore) | A permanent operational mode for Firestore that maintains backward API and operational compatibility with legacy Google Cloud Datastore, disabling real-time listeners and collections. | Google Cloud Firestore Documentation |
| Error Budget | Chybový rozpočet (Error budget) | The mathematically defined tolerance for service unreliability over a measurement window: $1 - \text{SLO}$; used by SRE teams to govern deployment velocity and operational reliability. | Site Reliability Engineering (Google SRE Book) |
| Essential Contacts | Klíčové kontakty organizace (Essential Contacts) | A centralized Google Cloud resource configuration defining verified organizational contacts who receive automated notifications regarding billing, legal, product outages, and security incidents. | Google Cloud Resource Manager Guide |
| Eventarc | Eventarc (směrování událostí) | An asynchronous event routing fabric that captures system and audit events from Cloud Audit Logs, Pub/Sub, or third-party webhooks and delivers them to Cloud Run, Workflows, or GKE. | Google Cloud Eventarc Documentation |
| Firestore Native Mode | Nativní režim Firestore | The primary operational mode for Firestore featuring hierarchical collections and documents, ACID transactions, real-time client listeners, and offline mobile synchronization. | Google Cloud Firestore Documentation |
| Global External Application Load Balancer | Globální externí aplikační balancer | A proxy-based Layer 7 load balancer deployed across Google's Anycast edge that terminates client TCP/TLS connections close to the user and proxies requests across Google's private backbone to backend services. | Google Cloud Load Balancing Guide |
| Google Front End (GFE) | Google Front End (GFE hrana) | The edge infrastructure software and hardware appliances deployed across Google's global Points of Presence (PoPs) that terminate Anycast IP traffic, handle TLS handshakes, and route traffic into Google's core network. | Google Infrastructure Security Design Whitepaper |
| Hierarchical Firewall Policy | Hierarchická pravidla firewallu | An organization- or folder-level firewall rule container that enforces mandatory ingress and egress security boundaries across all projects and VPCs beneath it, evaluated prior to VPC firewall rules. | Google Cloud VPC Security Architecture |
| Identity-Aware Proxy (IAP) | Proxy řízená identitou (IAP) | An edge application security boundary that intercepts HTTPS requests to verify user identity and contextual access policies (device health, geolocation, IP) before granting access to internal applications. | Google BeyondCorp Enterprise Architecture |
| IAM Allow Policy | Povolující politika IAM (Allow policy) | A declarative JSON/YAML document binding one or more principals (members) to predefined or custom roles on a Google Cloud resource; permissions inherit down the resource hierarchy. | Google Cloud IAM Documentation |
| IAM Condition | Podmínka IAM (IAM condition) | A Common Expression Language (CEL) expression attached to an IAM policy binding that grants permissions only when contextual request attributes (time, date, IP, resource tags) evaluate to true. | Google Cloud IAM Conditions Guide |
| IAM Custom Role | Vlastní role IAM (Custom role) | A user-defined collection of granular permissions created at the project or organization level to enforce the principle of least privilege when predefined roles are overly broad. | Google Cloud IAM Architecture |
| IAM Deny Policy | Zakazující politika IAM (Deny policy) | A policy container that explicitly prevents principals from executing specific permissions regardless of their Allow policy grants, evaluated before Allow policies across the entire hierarchy. | Google Cloud IAM Deny Policies Guide |
| Managed Instance Group (MIG) | Spravovaná skupina instancí (MIG) | A pool of homogeneous Compute Engine instances created from an instance template and managed as a single entity with automated health-checking, auto-healing, multi-zone distribution, and autoscaling. | Google Compute Engine User Guide |
| Network Endpoint Group (NEG) | Skupina koncových síťových bodů (NEG) | A configuration object that specifies a collection of backend endpoints (IP/port, Serverless service, or PSC target) for Google Cloud load balancers. | Google Cloud Load Balancing Documentation |
| Organizational Policy Constraint | Omezení organizační politiky (Org policy constraint) | A centralized governance rule (boolean, list, or custom) defined at the Organization or Folder level that restricts resource configurations (e.g., disabling public IP assignment or external service accounts). | Google Cloud Org Policy Service Documentation |
| Predefined Role | Předdefinovaná role IAM | A Google-managed collection of permissions tailored to common job functions or service responsibilities, maintained and automatically updated by Google as new APIs land. | Google Cloud IAM Reference |
| Principal Access Boundary (PAB) | Hranice přístupu principála (PAB) | A security control that restricts the set of Google Cloud resources that a principal or federated workforce identity can access, preventing compromised credentials from accessing resources outside the boundary. | Google Cloud Security Whitepaper |
| Private Google Access | Soukromý přístup ke službám Google | A subnet-level VPC configuration that allows Compute Engine VMs without public IP addresses to reach Google Cloud APIs and services using Google's internal Anycast network. | Google Cloud VPC Networking Documentation |
| Private Service Connect (PSC) | Privátní propojení služeb (PSC) | A software-defined private networking mechanism that publishes and consumes managed services across different VPC networks or projects using private IP endpoints in the consumer VPC. | Google Cloud Private Service Connect Guide |
| Pub/Sub Ack Deadline | Lhůta pro potvrzení Pub/Sub (Ack deadline) | The time window (default 10 seconds, configurable up to 600 seconds) a subscriber has to acknowledge (`ack`) a received message before Pub/Sub marks it unacknowledged and redelivers it. | Google Cloud Pub/Sub Documentation |
| Pub/Sub Dead-Letter Topic | Téma pro nedoručené zprávy Pub/Sub (DLQ) | A secondary Pub/Sub topic configured on a subscription to receive messages that have exceeded the maximum allowed delivery attempts (`maxDeliveryAttempts`), isolating poisoned payloads. | Google Cloud Pub/Sub Developer Guide |
| Pub/Sub Ordering Key | Řadicí klíč v Pub/Sub (Ordering key) | A string attribute attached to published Pub/Sub messages that guarantees strict FIFO delivery order among all messages sharing that key within a given region or subscription. | Google Cloud Pub/Sub Developer Guide |
| Security Command Center (SCC) | Bezpečnostní velitelské centrum (SCC) | A centralized security management and risk governance platform for Google Cloud that monitors asset inventory, detects vulnerabilities, flags misconfigurations, and tracks active threats. | Google Cloud Security Command Center Guide |
| Service Account Impersonation | Převzetí identity servisního účtu (Impersonation) | A secure access pattern where a human user or workload generates short-lived OAuth 2.0 access tokens for a service account via the IAM Credentials API without requiring downloadable JSON keys. | Google Cloud IAM Best Practices |
| Service Agent | Servisní agent (Service agent) | A Google-managed service account (typically formatted `service-<project-number>@gcp-sa-<service>.iam.gserviceaccount.com`) that executes background operations on behalf of a specific GCP service. | Google Cloud IAM Architecture Guide |
| Shared VPC | Sdílené VPC (Shared VPC) | A centralized networking architecture where a single Host Project shares one or more VPC networks and subnets with multiple Service Projects, separating network administration from application workloads. | Google Cloud VPC Networking Architecture |
| Service Level Indicator (SLI) | Indikátor úrovně služeb (SLI) | A quantifiable metric measuring the performance and compliance of a service in real time, typically calculated as: $\frac{\text{Good Events}}{\text{Total Valid Events}} \times 100\%$. | Site Reliability Engineering (Google SRE Book) |
| Service Level Objective (SLO) | Cíl úrovně služeb (SLO) | A target reliability percentage agreed upon by engineering and product stakeholders over a specific compliance window (e.g., 99.9% of requests succeed with $< 200\text{ms}$ latency over 30 days). | Site Reliability Engineering (Google SRE Book) |
| Spanner Interleaved Table | Prokládaná tabulka ve Spanneru | A physical database layout pattern in Cloud Spanner that stores child table rows co-located in storage alongside their parent row sharing the same primary key prefix, enabling zero-network cross-table joins. | Cloud Spanner Schema Architecture Guide |
| Sustained Use Discount (SUD) | Sleva za trvalé využití (SUD) | An automatic, non-contractual Google Cloud discount of up to 30% applied to Compute Engine instances and Google Kubernetes Engine nodes running for more than 25% of a billing month. | Google Cloud Compute Engine Pricing Guide |
| TrueTime API | Rozhraní TrueTime (TrueTime API) | A synchronized clock infrastructure across Google data centers backed by GPS receivers and atomic clocks that provides bounded time uncertainty intervals $[t.earliest, t.latest]$, enabling lock-free serializability. | Spanner: Google's Globally-Distributed Database (OSDI 2012) |
| Uniform Bucket-Level Access (UBLA) | Jednotný přístup na úrovni bucketu (UBLA) | A Cloud Storage security model that disables legacy Object Access Control Lists (ACLs) entirely, managing all access exclusively through uniform Cloud IAM policies at the bucket level. | Google Cloud Storage Security Guide |
| VPC Network Peering | Propojení sítí VPC (VPC Peering) | A low-latency internal network connection between two separate VPC networks in Google Cloud that is non-transitive and carries private IP traffic across Google's internal backbone. | Google Cloud VPC Peering Architecture |
| VPC Service Controls (VPC SC) | Bezpečnostní perimetry VPC (VPC SC) | A security capability that creates an isolation boundary around multi-tenant Google Cloud resources (Cloud Storage, BigQuery, Cloud SQL) to prevent data exfiltration over public internet routes. | Google Cloud VPC Service Controls Architecture |
| Workload Identity Federation (WIF) | Federace identit pro pracovní zátěže (WIF) | A keyless authentication mechanism that allows workloads outside Google Cloud (AWS, Azure, GitHub Actions, GitLab CI) to exchange external OIDC/SAML tokens for temporary Google Cloud credentials. | Google Cloud IAM Workload Identity Federation Guide |
