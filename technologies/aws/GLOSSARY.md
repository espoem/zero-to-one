# Bilingual Glossary: AWS Architecture & Cloud Engineering

A comprehensive English ↔ Czech terminology index defining formal concepts across AWS account governance, IAM policy evaluation, software-defined networking, compute virtualization, serverless runtimes, distributed databases, messaging, and cloud security architectures.

---

| Auto Scaling Group (ASG) | Skupina automatického škálování (ASG) | A logical grouping of EC2 instances managed as a single unit with automated health monitoring, elastic scaling policies, and dynamic instance replacement across multiple Availability Zones. | AWS Auto Scaling Documentation |
| Availability Zone (AZ) | Zóna dostupnosti | One or more discrete data centers with redundant power, networking, and connectivity within an AWS Region, isolated from faults in other Availability Zones. | AWS Global Infrastructure Architecture |
| AWS CDK Aspect | Aspekt AWS CDK | A visitor pattern construct in the AWS Cloud Development Kit that traverses every node in a construct tree during synthesis to inspect, validate, or mutate resources. | AWS CDK Developer Guide |
| AWS Elastic Disaster Recovery (DRS) | Elastická obnova po havárii (DRS) | An automated AWS disaster recovery service that maintains continuous, block-level data replication from physical or virtual hosts into a low-cost staging area in a target AWS region. | AWS DRS User Guide |
| AWS Fault Injection Service (FIS) | Služba vkládání poruch (FIS) | A managed chaos engineering service on AWS that introduces controlled, real-world fault injections into production or staging environments with automated stop conditions. | AWS FIS User Guide |
| AWS KMS Grant | Udělení oprávnění KMS (Grant) | A temporary, programmatic access delegation mechanism in AWS KMS that grants specific cryptographic permissions to a principal without modifying the KMS Key Policy. | AWS KMS Developer Guide |
| AWS Secrets Manager Rotation | Rotace přihlašovacích údajů v Secrets Manager | An automated four-step lifecycle (create, set, test, finish) implemented via AWS Lambda that rotates database and API credentials without application downtime. | AWS Secrets Manager User Guide |
| Cellular Architecture | Celulární architektura | A software architecture pattern that partitions a monolithic system into independent, self-contained, identical mini-deployments (cells) to strictly bound the blast radius of failures. | AWS Well-Architected Framework (Reliability Pillar) |
| CloudFront Origin Access Control (OAC) | Řízení přístupu k počátku (OAC) | An AWS security feature that restricts direct access to S3 bucket origins or web origins, requiring requests to be authenticated and cryptographically signed (SigV4) by CloudFront edge distributions. | Amazon CloudFront Security Guide |

| Compute Savings Plan | Úsporný plán pro výpočty (Compute Savings Plan) | A flexible commitment-based pricing model offering up to 66% discount in exchange for committing to a consistent hourly spend across EC2, Fargate, and Lambda anywhere. | AWS Savings Plans User Guide |
| Confused Deputy Problem | Problém zmateného zástupce (Confused deputy) | A computer security dilemma where a privileged service (the deputy) is tricked by an unauthorized caller into executing actions against target resources without proper scoping; mitigated in AWS via `aws:SourceArn` and `aws:SourceAccount`. | AWS IAM Security Reference & Best Practices |
| Cost and Usage Report (CUR 2.0) | Zpráva o nákladech a využití (CUR 2.0) | The most granular AWS billing dataset, delivered in Apache Parquet format partitioned in Amazon S3, detailing line-item costs across all accounts in an organization. | AWS Billing and Cost Management Guide |
| Customer Master Key / KMS Key | Klíč KMS (dříve Customer Master Key) | A primary logical cryptographic resource managed in AWS KMS containing key metadata and backing material used to encrypt and decrypt up to 4 KB of data directly, or to generate and protect envelope data keys. | AWS Key Management Service (KMS) Cryptographic Details |
| Dead-Letter Queue (DLQ) | Fronta nedoručených zpráv (DLQ) | A specialized queue attached to an SQS queue, SNS topic, or Lambda event source mapping that isolates messages that fail processing after exhausting their maximum receive count. | Amazon SQS Developer Guide |
| Delegated Administrator | Pověřený správce (Delegated administrator) | A member account in an AWS Organization granted administrative authority over a specific AWS service (e.g., IAM Identity Center, GuardDuty, Firewall Manager) without granting management account credentials. | AWS Organizations User Guide |
| DynamoDB Partition Key | Klíč oddílu DynamoDB | The primary hash attribute of an item passed through an internal MD5 hash function to determine the physical storage partition hosting the item and routing read/write operations. | Amazon DynamoDB Internal Architecture |
| DynamoDB Single-Table Design | Návrh jedné tabulky v DynamoDB | An advanced NoSQL data modeling pattern that stores heterogeneous entity types within a single DynamoDB table using overloaded generic partition and sort keys (`PK`/`SK`) to satisfy pre-computed access patterns with single network round-trips. | AWS Architecture Blog / DynamoDB Advanced Design Patterns |
| Envelope Encryption | Obálkové šifrování | A cryptographic architecture where plaintext data is encrypted using an ephemeral symmetric data encryption key (DEK), and the DEK itself is encrypted under a KMS key and stored alongside the ciphertext. | NIST SP 800-57 / AWS KMS Cryptographic Whitepaper |
| External ID | Externí identifikátor (External ID) | A shared secret string specified in the condition block of a cross-account IAM role trust policy (`sts:ExternalId`) that prevents confused deputy attacks in multi-tenant SaaS delegate integrations. | AWS IAM User Guide (Preventing Cross-Service Confused Deputy) |
| Firecracker MicroVM | Mikrovirtuální stroj Firecracker | An open-source, minimalist virtualization runtime built in Rust on Linux KVM by AWS, providing sub-5ms launch times and memory-safe hardware isolation for multi-tenant AWS Lambda and Fargate environments. | AWS Firecracker Design Specification |
| Gateway VPC Endpoint | Bránový koncový bod VPC | A high-throughput, horizontally scaled VPC routing gateway configured in subnet route tables that directs traffic directly to Amazon S3 or DynamoDB across the AWS internal network fabric without egress charges. | Amazon VPC User Guide (VPC Endpoints) |
| Global Accelerator | Globální akcelerátor | A networking service that routes user traffic over the AWS global edge network via static Anycast IP addresses, terminating TCP handshakes close to clients and routing over private backbones to regional endpoints. | AWS Global Accelerator Documentation |
| Global Secondary Index (GSI) | Globální sekundární index (GSI) | An asynchronous secondary index on a DynamoDB table with a partition key and sort key that can differ from the base table, containing a projected subset of attributes partitioned across the entire table space. | Amazon DynamoDB Developer Guide |
| IAM Identity Center | Centrum identit IAM (IAM Identity Center) | A centralized identity federation and single sign-on (SSO) service managing user identities, external IdP integrations (SAML 2.0 / SCIM), and multi-account AWS access via permission sets. | AWS IAM Identity Center User Guide |
| IAM Permission Boundary | Hranice oprávnění IAM (Permission boundary) | An advanced IAM governance mechanism using managed policies to set the absolute maximum permissions an identity-based policy can grant to an IAM user or role, preventing unauthorized privilege escalation. | AWS IAM User Guide (Delegating Responsibilities) |
| IAM Role | Role IAM | An AWS IAM identity that does not have long-term credentials (passwords or access keys) but is assumed dynamically by authorized principals to acquire temporary, short-lived security credentials via STS. | AWS IAM User Guide |
| Instance Metadata Service v2 (IMDSv2) | Služba metadat instancí v2 (IMDSv2) | A session-oriented host metadata service on EC2 (`169.254.169.254`) requiring a session token generated via `PUT` with `X-aws-ec2-metadata-token-ttl-seconds`, mitigating SSRF and open reverse-proxy credential leaks. | Amazon EC2 User Guide (Instance Metadata) |
| Instance Profile | Profil instance | A container for an IAM role used to pass role credentials automatically to an Amazon EC2 instance or ECS host upon bootstrap. | Amazon EC2 Security Guide |
| Interface VPC Endpoint (PrivateLink) | Rozhraní koncového bodu VPC (PrivateLink) | An elastic network interface (ENI) with a private IP address provisioned in a subnet that serves as an ingress entry point for AWS services, SaaS platforms, or internal services powered by AWS PrivateLink. | AWS PrivateLink User Guide |
| Lambda Event Source Mapping | Mapování zdrojů událostí Lambda | An AWS-managed polling mechanism that continuously reads records from stream- or queue-based services (SQS, Kinesis, DynamoDB Streams) and invokes a Lambda function synchronously with batches of records. | AWS Lambda Developer Guide |
| Lambda Provisioned Concurrency | Předem připravená souběžnost Lambda | A runtime configuration that initializes and maintains a specified number of execution environments warm and ready to respond instantly to incoming invocations, eliminating cold start latency. | AWS Lambda Developer Guide |
| Lambda Reserved Concurrency | Vyhrazená souběžnost Lambda | An allocation configuration that sets a guaranteed concurrency pool for a specific Lambda function while simultaneously acting as a hard upper bound ceiling to prevent runaway concurrency and backend saturation. | AWS Lambda Developer Guide |
| Lambda SnapStart | Rychlý start Lambda (SnapStart) | A cold-start optimization for managed runtimes that initializes the execution environment, takes a point-in-time microVM memory and disk snapshot, and caches it to restore execution state in sub-millisecond latencies. | AWS Lambda Developer Guide |
| Lifecycle Hook | Záchytný bod životního cyklu (Lifecycle hook) | An Auto Scaling mechanism that pauses the launch or termination sequence of an EC2 instance, enabling custom configuration scripts, health draining, or data export tasks before instance state finalization. | Amazon EC2 Auto Scaling User Guide |
| Network Access Control List (NACL) | Síťový seznam řízení přístupu (NACL) | A stateless, subnet-level Layer 4 firewall evaluating numbered inbound and outbound rules sequentially, requiring explicit configuration of ephemeral port ranges for return traffic. | Amazon VPC User Guide (Network ACLs) |
| Nitro System | Systém Nitro | The underlying hardware platform for modern EC2 instances that offloads hypervisor, storage (EBS), networking (ENA), and security functions to dedicated custom ASIC cards, freeing nearly 100% of host CPU/memory for workloads. | AWS Nitro Architecture Whitepaper |
| OpenID Connect (OIDC) Federation | Federace OpenID Connect (OIDC) | A keyless identity federation architecture allowing external CI/CD platforms (GitHub Actions, GitLab CI) to exchange short-lived OIDC JWTs for temporary AWS STS credentials via `AssumeRoleWithWebIdentity`. | AWS IAM User Guide (OIDC Federation) |
| Organizational Unit (OU) | Organizační jednotka (OU) | A hierarchical container for AWS accounts within an AWS Organization used to apply Service Control Policies and governance guardrails uniformly across groups of accounts. | AWS Organizations User Guide |
| Origin Access Identity (OAI) | Identita přístupu k počátku (OAI) | A legacy virtual CloudFront identity used to restrict S3 bucket access to CloudFront distributions, superseded by Origin Access Control (OAC). | Amazon CloudFront Legacy Documentation |

| RDS Aurora Storage Engine | Úložný stroj Aurora | A distributed log-structured storage subsystem that replicates database write log records across 6 storage nodes distributed over 3 Availability Zones, using a 4-of-6 quorum for write commits and 3-of-6 for read repairs. | Amazon Aurora Architectural Whitepaper |
| RDS Proxy | Proxy pro relační databáze (RDS Proxy) | A fully managed, high-availability database proxy for Amazon RDS and Aurora that pools and multiplexes database connections, reducing failover times by up to 66% and shielding backends from connection storms. | Amazon RDS Proxy Documentation |
| Recovery Point Objective (RPO) | Cílový bod obnovy (RPO) | The maximum acceptable data loss measured in time between the last persistent transaction and a disaster event, dictated by continuous data replication frequency. | AWS Well-Architected Reliability Pillar |
| Recovery Time Objective (RTO) | Cílový čas obnovy (RTO) | The maximum acceptable duration of service downtime before business operations must be restored after a disaster event, governed by infrastructure automation. | AWS Well-Architected Reliability Pillar |
| Resource Control Policy (RCP) | Zásada řízení prostředků (RCP) | A central preventive governance policy managed in AWS Organizations that sets the maximum permissions boundaries on resource-based policies across accounts, enforcing organization-wide data perimeters. | AWS Organizations User Guide (RCPs) |
| Route 53 Resolver | Překladač Route 53 (Route 53 Resolver) | The hybrid DNS service in Amazon VPC that responds to local DNS queries and forwards conditional domain queries between on-premises DNS servers and private hosted zones via inbound/outbound endpoints. | Amazon Route 53 Documentation |

| S3 Express One Zone | S3 Express v jedné zóně | A high-performance, single-AZ S3 storage class designed to deliver consistent single-digit millisecond data access latencies and 10x higher request rates than S3 Standard for latency-sensitive workloads. | Amazon S3 Express One Zone Overview |
| S3 Object Lock | Zámek objektů S3 (Object Lock) | A WORM (Write Once, Read Many) compliance mechanism that prevents S3 objects from being deleted or overwritten for a fixed retention duration (Governance mode or Compliance mode) or legal hold. | Amazon S3 User Guide (Object Lock) |
| S3 Strong Read-After-Write Consistency | Silná konzistence čtení po zápisu v S3 | A foundational storage guarantee in Amazon S3 ensuring that immediately following a successful `PUT`, `POST`, or `DELETE` of an object, subsequent read requests (`GET` or `LIST`) immediately return the updated object or state. | Amazon S3 Consistency Model Whitepaper |

| Service Control Policy (SCP) | Zásada řízení služeb (SCP) | A central preventive guardrail policy in AWS Organizations that defines the maximum available permissions for IAM identities in member accounts and OUs, overriding any identity-based administrator grants. | AWS Organizations User Guide (SCPs) |
| Shuffle Sharding | Náhodné sdílené rozdělení (Shuffle sharding) | An advanced multi-tenant routing technique that assigns each customer to a unique combination of $k$ nodes out of $N$ total nodes, reducing blast radius and poison-pill overlap to near zero. | Amazon Builders' Library (Shuffle Sharding) |
