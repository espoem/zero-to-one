# AI Engineering Glossary

Bilingual English ↔ Czech terminology index for the **AI Engineering** track, spanning LLM inference mechanics, prompt and context engineering, RAG retrieval, agent harnesses, MCP, evaluation metrics, LLMOps, and the AI security stack.

> [!IMPORTANT]
> Terms shared with the repository root glossary (`Idempotence / Idempotency`, `Backpressure`, `Circuit Breaker`, `Load Shedding`, `Inverted Index`, `BM25 (Okapi BM25)`) are preserved verbatim from root `GLOSSARY.md`.

| English Term | Czech Term | Definition & Context | Primary Reference |
| :-- | :-- | :-- | :-- |
| **Byte-Pair Encoding (BPE)** | **Kódování dvojic bajtů (BPE)** | A subword tokenization algorithm that iteratively merges the most frequent adjacent byte or symbol pairs to build a fixed-size vocabulary balancing rare-word coverage and sequence length. | Sennrich et al. (2016), Gage (1994) |
| **Context Engineering** | **Kontextové inženýrství** | The systematic discipline of assembling, ordering, compressing, and budgeting all information entering an LLM context window (system rules, memory, retrieved chunks, tool schemas, history) to maximize signal-to-token ratio. | Anthropic Engineering, AI Engineering Standards |
| **Grammar-Constrained Decoding (CFG / FSM)** | **Dekódování omezené gramatikou (CFG / konečný automat)** | An inference decoding technique that compiles a JSON Schema or Context-Free Grammar into a pushdown automaton / token mask, setting invalid token logits to $-\infty$ at each step. | XGrammar (Dong et al.), Outlines |
| **Retrieval-Augmented Generation (RAG)** | **Generování rozšířené o vyhledávání (RAG)** | An architecture that grounds LLM generation in external, non-parametric knowledge retrieved dynamically at query time rather than relying solely on parametric model weights. | Lewis et al. (2020) |
| **Matryoshka Representation Learning (MRL)** | **Matrjoškové učení reprezentací (MRL)** | A training objective that encodes coarse-to-fine information across nested prefix dimensions of a single embedding vector so truncated prefixes remain valid representations. | Kusupati et al. (arXiv:2205.13147) |
| **Reciprocal Rank Fusion (RRF)** | **Fúze recipročního pořadí (RRF)** | A rank-aggregation algorithm combining multiple ranked retrieval lists without score calibration via $\sum_r 1 / (k + \text{rank}_r(d))$, typically with $k = 60$. | Cormack, Clarke & Buettcher (SIGIR 2009) |
| **Contextual Retrieval** | **Kontextové vyhledávání** | A chunk-enrichment technique that prepends a concise LLM-generated document context summary to each chunk before embedding and BM25 indexing to preserve disambiguating metadata. | Anthropic (2024) |
| **Late Interaction (ColBERT MaxSim)** | **Pozdní interakce (ColBERT MaxSim)** | A multi-vector retrieval paradigm storing per-token document embeddings and scoring relevance at query time via summed maximum cosine similarities across query tokens. | Khattab & Zaharia (arXiv:2004.12832) |
| **Hypothetical Document Embeddings (HyDE)** | **Embeddingy hypotetického dokumentu (HyDE)** | A zero-shot dense retrieval method that prompts an LLM to generate a hypothetical answer document and embeds that synthetic document to search the real corpus. | Gao et al. (arXiv:2212.10496) |
| **GraphRAG** | **Grafové RAG (GraphRAG)** | A structured retrieval architecture extracting an entity-relation knowledge graph, clustering nodes into hierarchical Leiden communities, and answering global queries via map-reduce over community summaries. | Edge et al. (arXiv:2404.16130) |
| **Agent Harness** | **Rámec řízení agenta (agent harness)** | The deterministic runtime envelope surrounding an autonomous LLM loop that enforces step/cost/time budgets, sandboxing, tool allow-lists, retries, checkpointing, and human interrupts. | Agent Systems Engineering |
| **Model Context Protocol (MCP)** | **Protokol kontextu modelu (MCP)** | An open, stateless JSON-RPC 2.0 protocol standardizing how AI host applications connect isolated 1:1 clients to external servers exposing tools, resources, and prompts. | MCP Specification (2026-07-28) |
| **Human-in-the-Loop (HITL)** | **Člověk ve smyčce (HITL)** | An operational control pattern that suspends automated execution at high-risk or uncertain boundaries to require explicit human approval, correction, or escalation before mutating state. | NIST AI RMF, LangGraph `interrupt()` |
| **Faithfulness (Groundedness)** | **Věrnost kontextu (uzemněnost)** | A RAG evaluation metric measuring the fraction of atomic factual claims in a generated answer that are directly entailed by the retrieved context chunks. | Ragas Documentation (0.4.x) |
| **Context Precision@K** | **Přesnost kontextu na pozici K** | A rank-aware retrieval quality metric evaluating whether ground-truth relevant chunks appear ahead of irrelevant chunks within the top $K$ retrieved results. | Ragas Documentation (0.4.x) |
| **Context Recall** | **Úplnost kontextu (pokrytí kontextem)** | A retrieval completeness metric measuring the fraction of claims in the reference answer that can be attributed to the retrieved context. | Ragas Documentation (0.4.x) |
| **LLM-as-a-Judge** | **LLM jako hodnotitel (LLM-as-a-Judge)** | An evaluation pattern using a calibrated LLM with structured rubrics to score model outputs or pairwise preferences, requiring controls for position, verbosity, and self-preference biases. | Zheng et al. (arXiv:2306.05685) |
| **Prefill vs. Decode** | **Fáze předplnění vs. dekódování** | The two phases of transformer inference: compute-bound parallel prompt ingestion (`prefill`, governing TTFT) and memory-bandwidth-bound autoregressive token generation (`decode`, governing TPOT). | Inference Serving Architecture |
| **Prompt Injection (Direct & Indirect)** | **Injekce promptu (přímá a nepřímá)** | An attack vector where untrusted user input (direct) or retrieved documents/tool outputs (indirect) override system instructions or hijack agent goals and tool invocations. | OWASP LLM01, MITRE ATLAS `AML.T0051` |
| **ML-BOM (Machine Learning Bill of Materials)** | **Kusovník strojového učení (ML-BOM)** | A standardized inventory (e.g., CycloneDX 1.7 `modelCard` + `dataset` components) recording model provenance, architecture, training data lineage, metrics, and vulnerabilities. | CycloneDX 1.7 (ECMA-424) |
| **Idempotence / Idempotency** | **Idempotence** | The property of an operation where multiple identical executions yield the exact same system state as a single execution (`f(f(x)) = f(x)`). | ISO/IEC 2382, RFC 9110 (HTTP Semantics) |
| **Backpressure** | **Zpětný tlak (_backpressure_)** | The flow-control protocol where a slow consumer signals an upstream producer that intermediate buffers are full, pausing or throttling production until capacity drains. | Reactive Streams Specification, Node.js Streams |
| **Circuit Breaker** | **Jistič (circuit breaker)** | A fault-isolation pattern or memory safeguard that trips to fail fast when an upstream dependency degrades or when a node's memory reservation approaches exhaustion. | Nygard (Release It!) |
| **Load Shedding** | **Shazování zátěže (load shedding)** | An overload defense mechanism that proactively rejects excess incoming requests when queue depth, event-loop delay, or resource utilization crosses a critical threshold. | Beyer et al. (Site Reliability Engineering) |
| **Inverted Index** | **Invertovaný index** | An indexing data structure mapping each unique lexical term (token) to a sorted postings list of document identifiers containing that term. | Manning, Raghavan & Schütze (Introduction to Information Retrieval) |
| **BM25 (Okapi BM25)** | **BM25 (Okapi BM25)** | A probabilistic ranking function multiplying inverse document frequency by a saturating term-frequency component normalized for document field length (`k1`, `b`). | Robertson & Zaragoza (2009) |
